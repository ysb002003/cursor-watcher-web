# Cursor Watcher

Official product site and public release host for **Cursor Watcher** — a Windows desktop app that monitors and manages multiple Cursor IDE / Agent instances.

- Site: https://ysb002003.github.io/cursor-watcher-web/
- Latest download: https://github.com/ysb002003/cursor-watcher-web/releases/latest

## Enable GitHub Pages

1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / root (`/`)
4. Save, then open the site URL above

## Release notes for the desktop app

Upload Windows installers / binaries as **Releases** on this repository. The desktop app’s update checker should point to:

```text
https://api.github.com/repos/ysb002003/cursor-watcher-web/releases/latest
```
